# NOTE DEL PROGETTO:

## Descrizione
Questo progetto contiene gli esercizi e il materiale per il corso di Basi di Dati. Include la progettazione del database, gli script SQL per la creazione delle tabelle, le query di prova e le eventuali note sul modello ER.

## Struttura dei file
- `README.md` - documentazione del progetto
- `schema.sql` - script per la creazione delle tabelle e dei vincoli
- `dati.sql` - script di popolamento con dati di esempio
- `query.sql` - query di esempio per interrogare il database

## Come usare
1. Importare gli script SQL nel proprio DBMS preferito (ad esempio MySQL, PostgreSQL, SQLite).
2. Creare il database e le tabelle eseguendo `schema.sql`.
3. Popolare il database con `dati.sql`.
4. Eseguire le query di esempio in `query.sql`.

## Note
- Personalizzare i nomi degli oggetti in base alle specifiche del corso.
- Verificare la compatibilità degli script con il DBMS utilizzato.
